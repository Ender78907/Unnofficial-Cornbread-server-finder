# Cornbread Finder v0.6.8 — Minecraft 26.2

Proyecto Fabric, Java 25. Ejecutar `gradlew.bat build` en Windows o `sh gradlew build` en Linux/macOS. Resultados en build/libs. No instalar el JAR con sufijo -sources.

Incluye Server Inspector, las opciones de reintento automático con excepción configurable de whitelist y copia de nombres individuales o de la lista completa de jugadores Online/Anteriores. Ambos interruptores de reintento vienen desactivados; se conservan en config/cornbread-finder.json.

Consultar LEEME.md y PRUEBAS_REALIZADAS.md en la raíz de la entrega para los detalles de uso y verificación.
