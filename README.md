# Cornbread's Server Finder 0.6.8

Mod de cliente para buscar servidores desde el menú multijugador de Minecraft Java Edition. Es un proyecto independiente que usa la base de datos de Cornbread2100.

## Instalación

Usá Java 25 y Fabric API para tu versión de Minecraft. Copiá el JAR correspondiente a la carpeta `mods` de tu instancia.

| Minecraft | Fabric Loader mínimo | Mod | Código fuente |
| --- | --- | --- | --- |
| 26.2 | 0.19.3 | [Descargar JAR](JAR/26.2/cornbread-finder-0.6.8.jar) | [Proyecto Gradle](Fuentes/Codigo_26.2/) |
| 26.3 | 0.19.5 | [Descargar JAR](JAR/26.3/cornbread-finder-0.6.8+mc26.3.jar) | [Proyecto Gradle](Fuentes/Codigo_26.3/) |
